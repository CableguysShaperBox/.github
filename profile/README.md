## 🧠 Overview

Cableguys ShaperBox 3 is a versatile multi-effect plugin designed for detailed sound shaping, rhythmic modulation, creative mixing, and electronic music production. It combines a collection of specialized processing modules inside a single visual environment, allowing producers to build complex effect chains without constantly switching between separate plugins.

Its editable modulation system makes it possible to draw custom movement patterns, synchronize effects to the project tempo, respond to incoming audio, and create detailed rhythmic transformations. The plugin can be used for everything from subtle mix enhancement and dynamic control to pronounced stutters, glitches, distortion, filtering, stereo movement, and experimental sound design.

## Additional Information for Windows Users

ShaperBox 3 is designed to integrate directly into compatible Windows-based digital audio workstations. It can be used on individual tracks, buses, instruments, effects returns, and other signal paths where rhythmic movement or detailed modulation is required.

The visual waveform editor makes it possible to create custom patterns directly within the plugin rather than relying exclusively on preset modulation shapes. Tempo synchronization allows patterns to remain aligned with the musical grid, while audio and sidechain triggering can produce effects that react dynamically to drums, vocals, instruments, or other source material.

Because ShaperBox 3 can combine several processing stages and intensive modulation, CPU usage may vary depending on the number of active Shapers, project complexity, sample rate, buffer settings, and the capabilities of the host system.
